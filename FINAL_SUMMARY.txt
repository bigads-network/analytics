================================================================================
                        CRITICAL BEHAVIOR CHANGES
================================================================================

1. NO MORE BLOCKING
   - Every transaction returns instantly
   - No waiting for RPC responses in HTTP handler
   - All RPC work happens asynchronously in background

2. LOCAL NONCE MANAGEMENT
   - Nonces initialized at startup from blockchain
   - Incremented locally for each transaction
   - Synced from blockchain every 5 minutes
   - Synced from blockchain on actual nonce error (rare)

3. FIRE-AND-FORGET SENDS
   - wallet.sendTransaction() never awaited
   - Called with .then() for success tracking
   - Called with .catch() for error handling
   - Returns immediately to allow next transaction

4. GRACEFUL ERROR HANDLING
   - If transaction fails: counted as failed, not blocking
   - If nonce error: synced from blockchain once, then retried
   - If RPC error: provider marked failed, different provider used next time
   - No cascading failures, no system hangs
